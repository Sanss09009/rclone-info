Rclone Google Drive

This website provides information about a personal OAuth application used to connect Google Drive with Rclone.

Application Purpose

This application is configured for personal use to access Google Drive through Rclone.

Features

  • Browse Google Drive files and folders.
  • Upload and download files.
  • Copy files between local storage and Google Drive.
  • Synchronize files using Rclone.

Authentication

Access to Google Drive is authorized through Google's OAuth 2.0 authentication system. The application only accesses data permitted by the account owner.

Privacy

For information about data access, storage, and privacy, please read our Privacy Policy.
